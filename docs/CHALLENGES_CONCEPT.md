# Концепт: «Дуэли» — PRIDE Poker Club

> Статус: **концепт, утверждён к проработке макетов** (28.06.2026). Реализации ещё нет.

## 1. Цель
Поднять вовлечённость через личное соперничество поверх общего рейтинга. Игрок вызывает другого на конкретный турнир; победитель определяется по очкам за этот турнир. Публичная доска дуэлей и таблица побед добавляют движа и повод прийти и обыграть конкретного человека.

## 2. Суть одной строкой
*A вызывает B на турнир X → B принимает до 20:00 → оба играют → у кого больше очков за этот день, тот выиграл дуэль → результат идёт в публичную таблицу.*

## 3. Кто участвует
- Только **пользователи приложения** (профиль в Supabase + telegram_id). Кто не заходил — вызвать нельзя. Сейчас таких 33.
- **Дубли ников** сводятся к одному каноническому telegram-id:
  - «Асакура ХАО» → **@Lionello1993** (`1719603564`);
  - «Ерин Никита» → **@erinnikita** (`200646836`).
  - Остальные аккаунты-двойники в пул вызовов не попадают. Механика — справочник «ник → канонический telegram-id» для исключений.

## 4. Источник турниров
- В начале недели админ присылает **расписание** (день / дата+время / название / ссылка / описание).
- Оно парсится и заливается в Supabase (оживляем `games`: `title, date, time, link, description`).
- На эти турниры вешаются вызовы.
- Бонус: расписание даёт **названия турниров заранее** → ручной занос названий в `manual-tournaments.json` не нужен; постфактум остаётся сверить только победителя по листу.

## 5. Жизненный цикл вызова
```
СОЗДАН (pending)
  ├─ принял            → ПРИНЯТ (accepted)
  ├─ отклонил          → ОТКЛОНЁН (declined)
  ├─ вызывающий отозвал→ ОТМЕНЁН (cancelled)
  ├─ наступило 20:00   → ПРОТУХ (expired)
  └─ набралось 2 принятых дуэли → АВТО-ОТМЕНА (auto-cancelled)

ПРИНЯТ → после турнира:
  ├─ оба сыграли       → РЕШЁН (resolved): победа / поражение / ничья
  └─ кто-то не пришёл  → ОТМЕНА ПО НЕЯВКЕ (void, в таблицу не идёт)
```

## 6. Правила исхода
- Победитель — у кого **больше очков** за дату турнира (из рейтингового Google-листа).
- **Неявка любого** (нет очков за дату) → дуэль **не засчитывается** (void).
- **Поровну очков** → **ничья**.
- Расчёт **отложенный** — когда админ забьёт очки в лист. До этого дуэль «ждёт результат».

## 7. Лимиты и анти-абьюз
- **До 2 активных (принятых) дуэлей** на игрока за турнир, с **разными** соперниками.
- **Одна дуэль на пару** за турнир.
- Висящие вызовы слот не занимают; набралось 2 принятых → остальные висящие авто-отменяются («кто первым принял»).
- **Дедлайн принятия — 20:00** игрового дня (фикс). ⚠️ Для ранних турниров (17:00/19:00) приём закроется после старта — осознанный компромисс, пишем в инструкции.
- **Повторный вызов после отказа** на тот же турнир — нельзя; на следующий — можно.
- **Отзыв** не принятого вызова — можно.
- **Себе** вызов бросить нельзя.

## 8. Уведомления
Основной канал — **в приложении** (бейдж + экран «Дуэли»). ТГ-бот — **догоняющий** (только активировавшим бота; 100% не гарантируем). События (5):
1. Тебе бросили вызов (кнопки Принять/Отклонить).
2. Твой вызов приняли.
3. Твой вызов отклонили.
4. Результат дуэли (обоим): выиграл / проиграл / ничья / отмена.
5. Напоминание о висящем вызове перед 20:00.

## 9. Таблица вызовов (доска)
- **Публичная**, видят все.
- Рейтинг по **W–L–D**, сортировка по победам (или нетто = победы − поражения).
- Ничьи и отмены по неявке в победы/поражения не идут.
- *На будущее:* **ELO** (обыграл сильного — больше очков) как апгрейд.

## 10. UI / навигация
- **«⚔️ Дуэли» — 5-я вкладка** нижнего меню (Игры · Рейтинг · Легенды · Игроки · Дуэли). Центральный хаб: входящие (Принять/Отклонить) · мои активные дуэли · история · публичная таблица W–L–D. **Бейдж** на иконке при новом вызове/результате.
- **Карточка турнира** (вкладка «Игры»): кнопка «⚔️ Бросить вызов» + список активных дуэлей этого турнира.
- **Выбор соперника** — список игроков приложения (с @username для различения дублей).

## 11. Данные (эскиз, Supabase)
- `games` (оживляем): `id, title, date, time, link, description`.
- `challenges`: `id, tournament_id, challenger_id, opponent_id, status, result, challenger_points, opponent_points, created_at, responded_at, resolved_at`.
- Таблица W–L–D — производная (вью) из решённых дуэлей.

## 12. Инструкция для игроков (тезисы)
- Вызвать можно **только того, кто заходил в приложение**.
- Принять вызов нужно **до 20:00** (для ранних турниров приём может закрыться после старта — принимайте заранее).
- Победа — **по очкам** за турнир; не пришёл — отмена; поровну — ничья.
- На один турнир — **до 2 дуэлей**.
- Все дуэли **публичны**.

## 13. Ограничения и риски
- ТГ-доставка best-effort — часть пушей не долетит; страхуемся бейджем.
- Отложенный расчёт — пока лист не заполнен, дуэль «ждёт результат».
- Анти-чит на 20:00 дырявый для ранних турниров (принято).
- Неявка = void — лазейка: испугался проигрыша → не пришёл → обнулилось.
- Подсистема `games`/`registrations` сейчас пустая — оживляем через расписание.
